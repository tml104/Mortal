# 08: 从 chunks 完成主模型训练并保存训练产出

**What to build:** 训练入口能从完整 chunks 数据集随机初始化主模型，按批准的目标完成一轮有界训练，产生可读取的训练状态和 TensorBoard 指标。入口和核心训练逻辑保持在同一训练脚本中。

**Blocked by:** 07 — 确定性读取 chunk 并在设备上跨块组 batch。

**Status:** ready-for-agent

- [x] 使用配置驱动的入口和已确认网络规模，默认 CUDA、batch=1024、AMP 开启、compile 关闭、cuDNN benchmark 开启；关键运行参数可配置。
- [x] 从头生成主 seed，按约定处理专用训练产出目录，第一步更新前保存初始 checkpoint；配置和奖励源权重不被清理。
- [x] 新实现 Q 值回归、CQL 与局结束后顺位损失，以及批准的 AdamW、weight decay 和恒定学习率行为，不导入旧训练函数。
- [x] 正常 batch 与最终小 batch 都进行一次优化尝试，不做梯度累积、额外尾批梯度缩放或数据填充。
- [x] AMP 的优化尝试和 scaler 更新完成后才推进已消费样本位置；预取不能提前提交位置，AMP 跳过更新仍视为已消费。
- [x] checkpoint 包含三网络、优化器及学习率、AMP、必要随机数、seed、epoch、样本位置、数据生成 ID 和必要参数；以原子替换保存一个最新文件。
- [x] 训练指标按实际样本数汇总，默认每 100 batch 写日志；周期及结束保存接口为后续验证和恢复提供完整状态。
- [x] 用小型临时 chunks 和实际模型类验证一次完整训练更新、尾批、初始状态保存与产物可读性；这里只验收从头训练路径，验证与完整恢复由后续票接入。
