# 05: 全量顺序生成固定样本数的跨盘数据集

**What to build:** 用户通过预计算入口将有效的 train/val 牌谱全部按顺序展开，生成固定样本数的无损 chunk，按配额分布到 C/D，并获得训练端能够直接读取的完整数据集描述。

**Blocked by:** 03 — 单份牌谱生成六元样本并完成无损缓存往返。

**Status:** ready-for-agent

- [x] 独立入口读取已确认配置，默认每批四份文件交给 Rust 并行提取，按文件、玩家和决策顺序消费；Rust/PyTorch 线程数可配置，默认各四。
- [x] 使用预分配 buffer，默认每满 16,384 个样本形成一块；可跨牌谱分块，各 split 的最后余量也落盘，train/val 不混块、不打乱或丢样本。
- [x] 每个 chunk 完整写入一个卷，train 优先 D 再 C、val 写 C；遵守 440/320 GiB 的默认预算，预算和专用位置按配置解析。
- [x] 提供项目内统一入口；目录或链接冲突时停止，初始化清理仅限已批准的专用 chunk/临时 chunk。
- [x] 从头创建生成 ID；每块先发布文件再原子提交进度，JSON 失败立即停止；记录下一源样本位置和已提交字节数。
- [x] 完成描述保存 split 计数、尾块数量和连续 ID 分配区间，可据此构造路径；不维护逐块增长的大路径清单或内容哈希。
- [x] 全部 train/val 提交后标记完成，再次启动正常退出；错误直接终止，不在此阶段修补或隔离牌谱。
