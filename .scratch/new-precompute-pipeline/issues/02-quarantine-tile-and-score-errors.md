# 02: 隔离牌库存和点数不一致的牌谱

**What to build:** 在独立筛选入口中增加已确认的麻将基础规则检查，使协议可读但物理牌或点数不一致的牌谱被正确隔离，合法特殊结算能够保留。

**Blocked by:** 01 — 独立扫描并隔离协议损坏的牌谱。

**Status:** ready-for-agent

- [x] 按牌的物理来源与移动检查库存；摸牌、弃牌、副露对同一张牌的引用不重复计数。
- [x] 普通五与赤五合计最多四张，每门赤五最多一张；覆盖初始手牌、后续摸牌和宝牌指示等信息。
- [x] 多家和牌重复公开同一里宝牌指示信息不会被重复计数；不同指示位置恰好同牌面仍按不同实体处理。
- [x] 按总计 100,000 点且包含供托的规则验证守恒，检查每家分数的局间衔接；正确处理已接受立直和多个结算 deltas。
- [x] 合法负分终局、供托支付与终局供托归属不会被误判；检查范围不扩张为重新实现整套和牌计点算法。
- [x] 规则错误通过已有隔离和报告路径处理，保留具体规则及牌谱位置上下文。
- [x] 通过公开筛选入口验证代表性的合法日志与最小违规变体；正例包含副露、赤牌、供托、多家和牌和负分终局。
