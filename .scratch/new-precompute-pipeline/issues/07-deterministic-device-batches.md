# 07: 确定性读取 chunk 并在设备上跨块组 batch

**What to build:** 完整数据集能够按给定 seed 和 epoch 产生确定性样本流，CPU 只预取一块，目标设备按 batch 恢复六元样本，跨 chunk 拼接并保留尾批；给定消费位置时可直接继续读取。

**Blocked by:** 05 — 全量顺序生成固定样本数的跨盘数据集。

**Status:** ready-for-agent

- [x] 从完整描述的区间构造统一 chunk 列表和各块样本数，不扫描并采纳额外文件，不读取原牌谱或调用 GRP。
- [x] 先打乱 chunk，再由 seed、epoch、split、chunk ID 独立派生块内排列；结果不依赖此前访问顺序或预取进度。
- [x] CPU 解压紧凑表示并最多预取下一块，当前紧凑表示在目标设备按批索引展开；完整 observation 不整块常驻设备。
- [x] 跨块组 batch 时六个字段始终对齐，只有整个数据集尾部可以不足一批；余样不会无意持有完整 dense chunk。
- [x] 根据已消费样本数及块样本前缀累计直接定位，不从头读取解码；不同 epoch 可重新排列，固定输入的重建结果一致。
- [x] 读取和预取本身不提交训练进度；缺失文件、格式或解压错误直接向调用方抛出。
- [x] 验证 CPU/GPU 解码精确性、两盘块列表、尾块被打乱到中间、跨块 batch、单样本尾批和直接定位；GPU 验证有设备时实际运行并记录结果。
