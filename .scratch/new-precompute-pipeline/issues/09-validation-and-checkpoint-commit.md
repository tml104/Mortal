# 09: 将固定子集及全量验证接入保存边界

**What to build:** 训练按约定周期评估固定验证子集，每轮结束评估全量 val，并且只有完整验证成功后才发布对应 checkpoint 和 epoch 完成状态。

**Blocked by:** 08 — 从 chunks 完成主模型训练并保存训练产出。

**Status:** ready-for-agent

- [x] 默认每 1,000 个训练 batch 评估固定 131,072 个验证样本，不足时全取；独立 validation seed 默认 0，与训练轮次和主 seed 无关。
- [x] 每轮结束遍历全部 val；验证只消费 chunks，不生成梯度或更新网络状态，完成后正确恢复训练模式。
- [x] 汇总总损失、各分项损失、顺位准确率、Q 与目标均值等批准指标，按实际样本数加权。
- [x] 验证整体完成后才原子提交对应 checkpoint；轮末全量验证完成后才增加已完成 epoch 数。
- [x] 周期边界与轮末重合时共用一次最终提交，避免提前发布完成状态或重复保存。
- [x] 验证失败或中断不覆盖上一份完整 checkpoint，不保存半次验证游标；只维护一个最新状态。
- [x] 用可独立计算的指标案例和临时数据验证固定子集、全量覆盖、尾批权重、模型状态保持以及验证失败时提交不前移。
