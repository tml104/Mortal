# 04: 完成样本适用性筛选并支持中断续扫

**What to build:** 筛选入口在基础规则通过后实际提取样本，筛掉当前链路无法使用的输入，并在中断后从已提交的文件名边界继续，形成可供全量预计算使用的最终筛选结果。

**Blocked by:** 02 — 隔离牌库存和点数不一致的牌谱；03 — 单份牌谱生成六元样本并完成无损缓存往返（提供共享格式与样本约束）。

**Status:** ready-for-agent

- [x] 使用目标 libriichi 提取路径检查动作/mask、非空视角字段对齐、局索引、观测形状、有限值和编码范围。
- [x] 引用共享格式约束，不依赖预计算私有奖励生成器；筛选不加载或运行 GRP 权重。
- [x] 合法空视角被保留，包括空视角特殊 dones 返回值；全谱零样本或超出 60 局容量按“本链路不可用”隔离，不截断数据。
- [x] 区分规则错误、模型输入不兼容与运行故障；未知 Rust panic 停止并保留文件上下文，不广泛吞掉中断异常。
- [x] 默认每检查 100 份提交小型扫描进度，结束时提交余量；游标是 split 与最后处理的相对路径。
- [x] 恢复只处理严格大于游标的现存文件，游标对应文件已隔离也可恢复；已检查但未提交的有效文件允许重查。
- [x] 已完成扫描再次启动正常退出，显式重扫不清空隔离区；报告不作为恢复依据，不承诺恰好一次记录。
- [x] 用临时目录验证空视角、全谱零样本、容量超限、动作不合法，以及移动前后和进度提交前后的中断续扫。
