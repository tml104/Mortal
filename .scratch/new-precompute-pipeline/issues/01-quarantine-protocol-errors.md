# 01: 独立扫描并隔离协议损坏的牌谱

**What to build:** 用户通过独立配置启动筛选，就能按稳定顺序扫描 train/val，将压缩、文本、JSON、必要字段或对局边界损坏的牌谱移入隔离区，并获得明确原因。本票交付协议层面的完整扫描与隔离路径；牌库存、点数和样本适用性由后续票补齐。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 按已确认的入口分组和限定导入方式提供可单独启动的筛选入口；其导入和帮助输出不移动数据或启动模型。
- [x] 使用新独立配置，按 split 和相对路径字典顺序递归发现牌谱；配置读取与排序能力供后续入口共用。
- [x] 检查 gzip、UTF-8、JSON、必要协议字段，以及单场对局首尾、局边界和结算完整性；允许连续多家和牌结算。
- [x] 将明确协议错误的整份牌谱移入隔离区，保留 split 和原相对目录；已有同名目标时报错而不覆盖。
- [x] 用一个 JSONL 报告记录源、目标和原因；不计算文件或源码哈希，不执行 GRP 奖励推理。
- [x] 权限、存储和未知程序异常停止扫描并保留源文件，不统一归类为坏牌谱。
- [x] 用隔离的有效/损坏日志覆盖实际入口、文件移动、报告和目标冲突；不会接触真实源牌谱或现有实验配置。
