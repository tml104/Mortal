**需求依据：** 用户本轮追加的收尾要求；沿用规格的独立链路、正式入口、数据保护和有限验证边界。

- [x] 根据本轮实现和验收记录列出一次性代码的具体清理清单，逐项说明用途已经结束及无正式调用方；不能仅凭文件未被 Git 跟踪或位于临时目录就判定可删除。
- [x] 清理本轮新增且仅用于一次性诊断、网格调参、临时测量或调试的脚本、临时测试驱动和配套临时配置；清理前将支持验收结论所必需的参数、环境、测量方法和结果留在验收记录中。
- [x] 移除正式实现中仅为实验留下的临时注入、调试输出、硬编码实验路径和失去用途的实验分支；同步修正实际受影响的引用，不借此扩展为无关重构。
