# 01: 显式迁移旧主策略 checkpoint 为原生 Conv2d 状态

**What to build:** 使用者指定当前旧预计算链路的完整 checkpoint 和新训练配置后，得到写入新目录、能够安全重新加载的原生 Conv2d checkpoint；模型可直接完成前向计算，优化状态与训练进度完整保留。迁移只生成恢复状态，不启动训练。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

实施状态：2026-10-08 已完成。

**规格覆盖：** I1、I2、I5、I6；为后续训练、推理和对局评测建立同一模型与持久化契约。

- [x] 提供独立迁移操作及其所需的新训练配置解析、示例与用法；源 checkpoint 显式指定，配置和源权重不位于迁移目标的清理范围内，不读取无关的筛选或奖励配置。
- [x] 建立可被新训练、推理、评测共享的原生 Conv2d 主干及新格式加载能力；对外保持 v4 观测、特征和动作接口，内部使用高度为 1 的二维卷积与 channels_last，正确调整通道注意力和展平顺序。
- [x] 保留 BN 参数、统计、计数、epsilon、momentum，以及冻结、模式切换和统计重置行为；DQN 与 AuxNet 的既有计算含义保持对应。
- [x] 仅支持当前旧预计算完整状态到新状态的显式转换；保留全部模型、AdamW 动量和 step、AMP、CPU/CUDA RNG、主种子、epoch、样本游标、累计样本及累计 batch。
- [x] 卷积权重和对应 AdamW 张量增加相同的高度维度，非卷积张量保持对应；Linear 与 Conv2d 权重仍进入原有衰减组，不能因参数顺序或类型变化错配优化状态。
- [x] 新 checkpoint 明确标识格式和模型结构，原子写入并使用安全权重加载；推理所需的模型加载不要求实例化优化器、AuxNet 或数据集。完整恢复字段不能由缺失值静默补齐。
- [x] 目标契约只进行规格允许的表示和 batch 变化，默认 batch 2048、学习率 1e-4；模型、损失、优化器、数据身份及验证语义受到必要一致性约束，不添加源码哈希。
- [x] 只清空未输出的旧训练展示指标窗口，保留最近验证信息的历史归属；不改写历史 batch 数，不将旧验证冒充为新实现已完成的验证。
- [x] 源状态与旧产出保持不变，拒绝已有非空目标、损坏状态和不支持的源格式；迁移不消费样本或推进任何模型/优化状态。
- [x] 迁移完成信息说明源、目标、保留进度、清空窗口及下一 50/500 周期位置。文档明确本操作完成后再独立启动训练，不提供逆向迁移或额外推理权重副本。
- [x] 通过公开迁移操作验证非零动量、BN 统计、AMP/RNG 和非零游标的转换与重新加载；以独立旧模型对照 FP32 前向、梯度和同 batch 的一次优化更新，浮点结果采用合理容差，状态映射精确对应。

**独立验收：** 用一个隔离的完整旧状态执行迁移，再重新加载产物并完成模型/优化状态对照；无需等待新训练循环或 mjai 入口实现。

**边界：** 本票在新增链路中完成迁移，不重构旧训练模块；无需另立跨仓库预重构任务。数据消费、生产训练恢复与协议入口分别由后续票据交付。
