# Log Viewer for mjai

This component is copied and modified from the artifacts generated by [gimite/mjai](https://github.com/gimite/mjai).

评测静态回放的新入口是 `build_replays.py`，支持实时分数、座次、供托、动作 Q 值和自适应布局。生成及打开方式见 [评测牌谱可视化回放](../docs2/evaluation-replay.md)。原 `files/js`、`files/css` 与 `index.example.html` 保留作为上游查看器参考。
