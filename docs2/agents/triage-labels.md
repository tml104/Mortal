# Triage Labels

工程技能的五种标准分诊角色映射如下。本项目使用本地 Markdown，将实际标签写入任务顶部附近的 `Status:` 行。

| 技能角色 | 本地任务标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理独立实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能要求应用分诊角色时，使用表中对应标签。后续调整项目标签时修改第二列。

Wayfinding 探索任务的执行状态遵循 `issue-tracker.md` 中的独立约定。
