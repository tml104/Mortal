# Domain Docs

本项目采用 single-context，Rust 与 Python 模块共享一个领域上下文。

## 探索前的阅读规则

- 阅读仓库根目录的 `CONTEXT.md`，了解已明确的领域术语和规则。
- 阅读 `docs2/adr/` 中与当前工作相关的架构决策。
- 如果这些文件尚不存在，直接继续工作，无需提醒缺失或建议预先创建；由 `/domain-modeling` 在术语或决策实际明确后按需创建。
- 判断当前行为仍遵循 `AGENTS.md` 的信息来源优先级，并回到源码与测试核实。

## 文档布局

所有路径相对仓库根目录：

- `CONTEXT.md`：唯一的领域上下文与术语表。
- `docs2/adr/<NNNN>-<slug>.md`：架构决策，从 `0001` 起使用未占用的顺序编号。

领域文档不拆分为多个上下文，ADR 统一放在 `docs2/adr/`；该目录沿用 docs2 的阅读笔记定位，不参与 mdBook 发布。

## 使用统一术语

任务标题、重构提案、诊断假设和测试名称涉及领域概念时，使用 `CONTEXT.md` 已定义的术语。

若所需概念不在术语表中，先核实是否为项目已有概念；确属缺口时，交由 `/domain-modeling` 记录。

## 显式指出决策冲突

提案与现有 ADR 冲突时，指出 ADR 编号、冲突内容和重新讨论的理由，保留原决策的可追溯性。
