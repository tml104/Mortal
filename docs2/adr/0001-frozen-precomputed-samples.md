# 固定六元样本、无损观测缓存与显式进度提交

新预计算链路将 v4 观测、动作、mask、折扣步数、冻结 Transformer-GRP 局奖励及局结束后顺位提前固化，训练只消费这些六元样本；改变样本生成语义时重建数据，以免后续实验重复执行昂贵的牌谱展开与奖励计算。

观测采用固定语义编码和 Zstd，保留原始 float32 精度；在约 629 GiB 的容量估算下，将独立 chunk 分布到 C/D 两盘并提供统一逻辑入口，接受 WSL 访问 Windows 文件系统的性能取舍。选择无损缓存是为了避免把观察值量化误差混入训练改动的比较。

预计算仅以小型进度 JSON 中已提交的 chunk 为有效数据，训练将模型、优化状态及已消费位置统一存入一个 checkpoint；允许重算未提交工作，不持久化大 buffer 或预取状态。同一次运行假定输入稳定，以生成 ID 和必要参数识别恢复对象，不采用源码或逐文件内容哈希。
